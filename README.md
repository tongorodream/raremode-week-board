# RareMode Week Board

An Obsidian view for TaskNotes tasks:

- seven-day project board on desktop;
- focused one-day view on mobile;
- previous/next day navigation on mobile;
- quick task creation inside a project group;
- completion checkboxes;
- drag and drop on desktop;
- on mobile, hold a task, hover over a day arrow, then drop it into the required project.

## Mobile installation with BRAT

1. Install and enable the **BRAT** community plugin in Obsidian.
2. Open **BRAT: Add a beta plugin for testing** from the command palette.
3. Enter `tongorodream/raremode-week-board`.
4. Enable **RareMode Week Board** under Community plugins.

The plugin reads and updates TaskNotes files in `TaskNotes/Tasks`.
