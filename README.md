# RareMode Week Board

An Obsidian view for TaskNotes tasks:

- seven-day project board on desktop;
- focused one-day view on mobile;
- previous/next day navigation on mobile;
- quick task creation inside a project group;
- project creation from the board toolbar;
- completion checkboxes;
- drag and drop on desktop;
- on mobile, hold a task, move it onto a day arrow, then drop it into a project target.

## Mobile installation with BRAT

1. Install and enable the **BRAT** community plugin in Obsidian.
2. Open **BRAT: Add a beta plugin for testing** from the command palette.
3. Enter `tongorodream/raremode-week-board`.
4. Enable **RareMode Week Board** under Community plugins.

## TaskNotes dependency

TaskNotes is optional. The board reads and writes TaskNotes-compatible Markdown files directly in:

- `TaskNotes/Tasks`;
- `TaskNotes/Projects`.

Without TaskNotes installed, the board still supports projects, task creation, completion, scheduling, and drag and drop. Install TaskNotes when you also want its native task editor, calendar, filters, and other advanced views.
